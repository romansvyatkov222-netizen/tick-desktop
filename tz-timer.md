# Техническое задание: десктопное приложение «Таймер» (Windows)

Референс дизайна: приложенный скриншот AmneziaVPN.

## 1. Цель
Приложение для Windows: обратный таймер с необязательным названием. Когда время вышло, поверх всех окон появляется модальное окно и играет звук, даже если приложение свёрнуто или спрятано в трей. Дизайн тёмный, в стиле liquid glass, композиция как у AmneziaVPN.

## 2. Стек (приоритет: минимальный вес исходников и .exe)
- **Tauri 2** (Rust и системный WebView2). Electron не использовать.
- **Фронтенд: чистые HTML, CSS и JavaScript (ES-модули), без фреймворков и сборщика.**
- **Иконки: Lucide** (SVG). Инлайнить только нужные: `house`, `history`, `play`, `pause`, `square`, `trash-2`, `bell-ring`, `x`, `chevron-down`. Библиотеку целиком не подключать.
- **Шрифт:** системный (`"Segoe UI Variable", Inter, sans-serif`) или один локальный woff2 (Inter, subset: кириллица, латиница, цифры). Без CDN, приложение полностью офлайн.
- **Хранение:** один JSON-файл в app data dir (через Rust-команды) или `localStorage`. Без баз данных.
- **Звук:** короткий сигнал, сгенерированный через Web Audio API (файл не нужен), или один маленький .ogg (до 50 КБ). Голосовой озвучки нет, только сигнал.
- **Профиль release** в `Cargo.toml`: `opt-level="z"`, `lto=true`, `strip=true`, `panic="abort"`, `codegen-units=1`.
- Лишних зависимостей быть не должно. Для трея используется встроенная возможность Tauri (`tray-icon`), для единственного экземпляра плагин single-instance.

## 3. Окно приложения
- **Одно основное окно фиксированного размера, вертикальное, как экран телефона.** Внутренняя область около **390×760 px** (примерно 1:1.9). `resizable: false`, кнопка «развернуть» отключена.
- **Заголовок окна нативный тёмный** (как у Амнезии): иконка, название «Таймер», кнопки «свернуть» и «закрыть». В конфиге тема `dark`. Своя рамка и прозрачное окно не нужны.
- **Закрытие через крестик не завершает приложение:** окно скрывается в **системный трей**, таймер продолжает идти.
- **Трей:**
  - левый клик по иконке показывает окно;
  - правый клик открывает меню «Открыть» и «Выход» (полный выход из приложения);
  - во всплывающей подсказке иконки показывается оставшееся время, если таймер идёт.
- Запускать можно только один экземпляр приложения. Повторный запуск показывает уже открытое окно.
- Автозапуск вместе с Windows не нужен.

## 4. Структура экранов
Нижняя панель навигации, как в Telegram, на всю ширину, в стиле стекла. Две вкладки: **«Главная»** (иконка `house`) и **«История»** (иконка `history`). У каждой иконка и подпись. Активная вкладка подсвечена акцентным оранжевым цветом, как домик на скриншоте.

### 4.1. Экран «Главная»
По композиции повторяет Амнезию:

1. **Центральное кольцо** (SVG-круг диаметром около 260 px, светлая тонкая обводка с мягким тёплым свечением, как на скриншоте). Внутри кольца:
   - **Состояние «ожидание»:** три **колёсика-пикера** «часы / минуты / секунды» в стиле iOS (вертикальная прокрутка колесом мыши и перетаскиванием, `scroll-snap`, центральное значение крупнее и ярче, соседние бледнее). Диапазоны: часы 0–23, минуты 0–59, секунды 0–59. Изначально 00:25:00 или последнее использованное значение.
   - **Состояние «идёт»:** крупные цифры `ЧЧ:ММ:СС`, обратный отсчёт до нуля. Цифры моноширинные (`font-variant-numeric: tabular-nums`), размер 56–72 px. Дуга обводки кольца плавно убывает по мере отсчёта.
   - **Состояние «пауза»:** те же цифры, мягкое мигание или приглушение.
2. **Нижняя «шторка»** в стиле стекла, как на скриншоте (скруглённые верхние углы, сверху маленькая «ручка»-полоска, декоративная):
   - поле ввода **«Название таймера»** (необязательное), например «программирование». Во время работы поле заблокировано и показывает название;
   - кнопки управления:
     - «ожидание»: большая кнопка **«Старт»**;
     - «идёт»: **«Пауза»** и **«Стоп»**;
     - «пауза»: **«Продолжить»** и **«Стоп»**.
3. Если название не введено, таймер всё равно запускается. В истории такая запись называется **«Без названия»**.
4. Запустить таймер на 00:00:00 нельзя: кнопка «Старт» неактивна, пока выбрано нулевое время.
5. Одновременно работает только один таймер.

### 4.2. Экран «История»
- Список завершённых запусков, новые сверху. В каждой карточке: название, заданная длительность, дата и время завершения, статус («Завершён» или «Остановлен вручную»).
- Кнопка **«Очистить историю»** с подтверждением.
- Пустое состояние: иконка и текст «Пока ничего нет».
- Хранится до 200 последних записей, история сохраняется между запусками.

## 5. Завершение таймера
1. **Модальное окно** открывается отдельным окном Tauri **поверх всех окон** (`always_on_top`), по центру экрана, с фокусом. Оно появляется даже тогда, когда основное окно свёрнуто или скрыто в трей. Без рамки, в том же стиле стекла. Содержимое: иконка `bell-ring`, заголовок «Таймер завершён», название таймера (или «Без названия»), заданная длительность, кнопка **«ОК»**.
2. **Звук:** короткий мелодичный сигнал. Играет, пока окно не закрыто, повторяется каждые 5–10 секунд. Автоотключение через 1 минуту. Звук работает при свёрнутом приложении.
3. **Точность:** время считается по метке окончания (`end_timestamp = now + duration`), а не декрементом через `setInterval`. Основной таймер живёт **на стороне Rust** (отдельная задача), потому что WebView может троттлить таймеры в свёрнутом состоянии. Rust отправляет событие `tick` в интерфейс и событие `finished` по окончании.
4. **Восстановление:** состояние таймера (`end_timestamp`, название, пауза и остаток) сохраняется на диск. Если приложение завершили и запустили снова, а таймер ещё не истёк, отсчёт продолжается. Если время вышло, пока приложение было закрыто, при запуске сразу показывается модальное окно.
5. После нажатия «ОК» запись попадает в историю со статусом «Завершён», главный экран возвращается в «ожидание».

## 6. Дизайн
- **Тёмная тема.** Фон почти чёрный (`#0c0c0f` – `#101014`), как у Амнезии. Поверх него два-три очень мягких размытых цветовых пятна (тёплый оранжевый и приглушённый фиолетовый) с низкой яркостью, чтобы стеклу было что преломлять, а общий вид оставался тёмным.
- **Акцентный цвет:** тёплый оранжевый (около `#f5a25d`). Он используется для активной вкладки, свечения кольца и ключевых кнопок.
- **Liquid glass** на шторке, нижней панели, карточках истории, поле ввода и модальном окне:
  - `backdrop-filter: blur(24px) saturate(170%)`;
  - полупрозрачная заливка `rgba(255,255,255,0.05–0.10)`;
  - тонкая граница 1 px `rgba(255,255,255,0.12–0.22)`;
  - внутренний блик сверху: `inset 0 1px 0 rgba(255,255,255,0.25)`;
  - мягкая внешняя тень;
  - необязательное жидкое преломление на краях через SVG-фильтр `feTurbulence` и `feDisplacementMap`. Если в WebView2 это работает плохо, оставить чистый CSS.
- **Кольцо в центре:** светлая тонкая обводка (2–3 px) с мягким тёплым свечением (`drop-shadow`). Во время отсчёта свечение слегка пульсирует (медленно, 3–4 с). Сворачивание окна паузит анимации.
- **Анимации:** 200–400 мс, `cubic-bezier(.2,.8,.2,1)`. Нажатие на кнопки: лёгкое уменьшение и усиление блика. Переход между вкладками: плавное появление. Уважать `prefers-reduced-motion`.
- **Иконки:** Lucide, толщина линии 1.75–2. Неактивные серые, активные оранжевые.
- **Типографика:** подписи светло-серые (`#9a9aa5`), заголовки белые, как на скриншоте.

(Значения цветов и размеров выше даны как ориентир. В коде они живут только в `tokens.css`, см. раздел 10.)

## 7. Нефункциональные требования
- Размер `.exe` до **~10 МБ**, исходники без `node_modules` и `target` до **~1 МБ**.
- Минимум потребления: при сворачивании и скрытии в трей анимации и перерисовка останавливаются, остаётся только таймер на стороне Rust.
- Приложение ничего не отправляет в сеть.
- Структура проекта:
  - `index.html`, `modal.html`, `app.js`, `modal.js`;
  - общие файлы: `tokens.css`, `glass.css`, `styles.css`, `config.js`, `strings.js`, `format.js`, `sound.js`, `icons.js`;
  - папка `icons/`;
  - `src-tauri/`: `main.rs`, `config.rs`, `tauri.conf.json`, `Cargo.toml`, иконка приложения и трея.
- Комментарии на русском там, где логика неочевидна.

## 8. Что должна выдать нейросеть
1. Структуру проекта и **все файлы целиком**.
2. `tauri.conf.json` с настройками главного и модального окон, темой, одним экземпляром приложения и `bundle.active: false`.
3. Rust-код: таймер, события, трей, скрытие в трей по крестику, открытие модального окна поверх всех окон, сохранение состояния.
4. Команду dev-запуска и команду сборки одного `.exe` без установщика (`--no-bundle`), плюс пояснения по оптимизации размера.
5. Список использованных иконок Lucide.

## 9. Критерии приёмки
- Время задаётся колёсиками, таймер запускается с названием и без него.
- Крестик скрывает окно в трей, таймер продолжает идти.
- По окончании поверх всех окон появляется модальное окно со звуком, в том числе если приложение скрыто в трее.
- Состояние таймера и история переживают перезапуск.
- Внешний вид близок к скриншоту Амнезии: кольцо, шторка, нижняя панель, оранжевый акцент, стекло.
- Собран один `.exe` без установщиков, размер в рамках лимита.

## 10. Правила для кода

**Без дублирования (DRY):**
- Любая логика, которая нужна в двух местах, выносится в общий модуль. Копировать код между главным и модальным окном нельзя.
- Общие для обоих окон файлы: `tokens.css` (переменные дизайна), `glass.css` (один класс `.glass` для всех стеклянных поверхностей: шторка, нижняя панель, карточки, модальное окно, поле ввода), `format.js` (одна функция форматирования времени `ЧЧ:ММ:СС` и длительности), `sound.js` (воспроизведение сигнала), `icons.js` (одна функция `icon(name)` для вставки SVG).
- Кнопки, карточки и поля используют общие CSS-классы с модификаторами, а не отдельные стили под каждое место.
- В Rust тоже общие функции: сохранение и загрузка состояния, открытие окна, отправка событий.

**Без хардкода:**
- **Дизайн:** все цвета, радиусы, размытие, тени, длительности и кривые анимаций лежат как CSS-переменные в `:root` файла `tokens.css`. В остальных стилях значений вроде `#f5a25d` или `300ms` быть не должно.
- **Настройки поведения (JS):** `config.js` содержит константы: интервал повтора звука, время автоотключения звука, лимит записей истории, диапазоны колёсиков, ключи хранилища, размеры кольца.
- **Настройки поведения (Rust):** отдельный блок `const` или файл `config.rs` с теми же настройками. Размеры окон задаются только в `tauri.conf.json`.
- **Тексты интерфейса** («Старт», «Без названия», «Таймер завершён» и т. д.) лежат в одном файле `strings.js`.
- Магических чисел и строк в логике быть не должно, только именованные константы.

**Общие правила:**
- Единый источник правды о состоянии таймера: Rust. Интерфейс только отображает события и отправляет команды.
- Функции короткие, у каждой одна задача. Названия понятные.
- Нет мёртвого кода, неиспользуемых зависимостей, закомментированных кусков и лишних абстракций. Всё должно быть как можно проще.
- Комментарии на русском объясняют «почему», а не «что».

## 11. Порядок работы и сборка
1. **Сначала не собирать exe.** Агент пишет весь код и запускает приложение в **dev-режиме** (`cargo tauri dev`), проверяет, что оно стартует, таймер идёт, трей и модальное окно работают, и сообщает результат.
2. **Release-сборка только после моего подтверждения.**
3. **Установщики не нужны.** В `tauri.conf.json` стоит `bundle.active: false`. Собирается **только один portable `.exe`**: `cargo tauri build --no-bundle`. Готовый файл лежит в `src-tauri/target/release/`. Файлы `.msi`, `.nsis` и подобные не создавать.
4. В конце агент называет путь к `.exe` и его размер.
5. Примечание: portable `.exe` использует системный WebView2. На Windows 10 и 11 он уже есть.
